| 기능 | 규모 | 완료 기준 |
|---|---|---|
| 체감 랜덤 보정 (최근 등장 제외 + 동네·카테고리 연속 억제) | 소 | 같은 조건 연속 생성 10회에 중복 스폿 없음 |
| 분위기 pill 4종 + ⋯더보기 | 소 | 기본 4종 노출, 인라인 펼침 |
| 추천 이유 1줄 + 검증 뱃지 | 소 | mood 태그 기반 자동 문구, verified만 뱃지 |
| 복사 텍스트 포맷 v2 | 소 | 카톡 붙여넣기 실물 확인 |

## 실행 순서

```
F1 (즉시) ──┬── F4 (병행, 하이쿠)
            └── S1~S7 디자인 확정 → F2 → F3
```

- F1+F4를 먼저 돌리고, 그 사이 SCREENS.md 기반 목업으로 디자인 결정 → F2, F3 순.
