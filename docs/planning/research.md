# 기능 기획 심층 검토 — 시장·트렌드·UX 리서치 (2026-08-16)

> 리서치 3팀(유사 앱 / 데이트 트렌드 / 심플 UX 패턴) 결과의 교차 분석.
> 컨셉 앵커: **"최대한 간단한 데이트코스 소개앱"**. 결정 사항은 PLAN.md에 반영한다.

## 1. 컨셉 검증 — "간단함"은 약점이 아니라 포지셔닝

- 시장의 모든 플레이어가 무겁다: 데이트팝(설치+콘텐츠 탐독+제휴딜), 데이트로드(포인트 장벽), 카카오맵 AI(채팅 입력+쿼터), 완벽한하루(서버·제휴 기반 → 정체 추정)
- **"설치·로그인·서버 없이 열자마자 코스 하나"를 주는 플레이어는 전무** — 우리의 빈 틈
- 20대 장소 최종 결정에서 AI 검색·요약 비중은 3%뿐 → 채팅형 AI로 가면 안 되는 근거. 우리는 "AI처럼 보이는 것"이 아니라 "버튼 몇 번 → 결과"가 맞음
- 데이트팝 600만 다운로드 = "코스 짜기 부담 해소" 수요 자체는 크다는 증명

## 2. 사용자 행동 파이프라인과 우리의 위치

```
발견(인스타 릴스·쇼츠 23~27%, 지도앱 검색 55~58%)
 → 검증(지도앱 리뷰·별점 57%)  ← ★ 신뢰는 네이버에 위임하는 게 정답
 → 코스화(수작업. 어떤 서비스도 못 함)  ← ★★ 우리가 서는 자리
 → 공유(카톡이 기본값)                    ← ★ 텍스트 복사 방향 정합
 → 이동(네이버지도 62%)                   ← ★ 지도 링크 품질이 핵심 경쟁력
```

## 3. 현재 기능 판정표

| 기능 | 판정 | 근거 |
|---|---|---|
| 슬롯 토글(낮/저녁/밤/숙박) | ✅ 존치 | 근교·반나절 트렌드 정합. "선택 최소화→자동 생성"은 시장 검증 패턴 |
| 지역 다중선택 | ✅ 존치 | 실사용 패턴 반영 완료 |
| 분위기 8종 pill | ⚠️ 노출 축소 검토 | 사전 필터가 무거우면 버튼 누르기 전에 결정 피로 발생 (원-액션 UX 연구). 데이터는 유지, UI만 접기 |
| 코스 자동 생성 + 근접 자동 | ✅ 존치 | 검증된 패턴 + 아무도 못 하는 "5초 결정" |
| 🔄 즉시 랜덤 교체 | 🔧 개선 | **체감 랜덤 보정 필요** — Spotify 교훈: 진짜 랜덤은 "고장" 소리 들음. 최근 등장 스폿 제외 + 같은 동네·카테고리 연속 억제 |
| 전체 다시 뽑기 | ✅ 존치 | |
| 네이버 지도 링크 | 🔧 강화 | 이동 62%가 네이버지도. **링크 정확도가 곧 제품 신뢰.** 검색어 정제는 완료, 향후 장소ID 딥링크 검토 |
| 텍스트 복사 | 🔧 개선 | 카톡 = 커플 공유 표준. Wordle 교훈: 텍스트도 포맷이 정형·예쁘면 퍼진다 → 복사 포맷 고급화 |
| 코스 저장(localStorage) | ⚠️ 재검토 | **iOS가 미사용 시 localStorage 임의 삭제** — 지킬 수 없는 약속. URL 인코딩 공유로 대체/보완 검토 |
| 스텝 카드 | 🔧 개선 | 사진·리뷰 없는 약점 → **한 줄 추천 이유 + "확인된 장소" 뱃지**가 최저비용 신뢰 장치 (설명은 짧게 — 길면 역효과) |

## 5. 하지 않을 것 (연구 근거로 기각)

- **UGC·커뮤니티·리뷰 기능** — 신뢰는 이미 네이버 리뷰(57%)에 있음. 콜드스타트만 안게 됨
- **틴더식 스와이프** — 결정 피로 재생산, "다음 카드 기대"가 만족도를 깎음. 현 구조(결과 먼저+교체)가 우수
- **채팅형 AI 인터페이스** — 최종 결정에서 AI 비중 3%. 카카오맵 AI와 정면 대결 회피
- **술·바 카테고리 확대** — 위스키 수입 -10%, 무알코올 재편. 오히려 러닝·산책·야간개장 전시 등 무알코올 저녁 데이터가 확충 우선
- **계정·서버·앱 설치** — 가벼움이 포지셔닝

## 6. 데이터 방향 시사점

- 밤(night) 슬롯: 바 위주 → **무알코올 심야 스폿**(야간개장 전시·야경 산책·심야 카페) 보강
- 낮 슬롯: **팝업스토어**(2025년 연 3,000개, 성수 연관)·러닝 코스·근교 반나절 스폿 보강
- 비용 메타데이터: 커플 83%가 데이트 비용으로 다툼 — price 필드 채우기가 생각보다 중요 (백로그: 예산 필터의 전제)
