## S1. 홈 — 첫 진입 (생성 전)

```
┌──────────────────────┐
│ 오늘 데이트    [저장한 코스] │
├──────────────────────┤
│ ✨ 오늘 8/16의 코스        │  ← 날짜 시드 고정, 콤팩트 카드 1장
│  ☀️카페A → 🌆식당B → 🌙바C │     (탭하면 결과 영역에 펼침)
├──────────────────────┤
│ 나만의 코스 만들기          │
│ 슬롯: ☀️■ 🌆■ 🌙□ 🏠□   │
│ 지역: [전체][서울][경기]…   │
│ 분위기: [로맨틱][힐링][미식]│
│        [핫플] [⋯더보기]    │
│ [ 코스 만들기 ]            │
└──────────────────────┘
```
- **설계 포인트**: 오늘의 코스는 "미리보기 1줄 요약"으로 콤팩트하게 — 히어로는 어디까지나 "코스 만들기". 오늘의 코스가 화면 절반을 먹으면 안 됨.

## S2. 홈 — 결과 (생성 후)

```
│ 서울 · 힐링 코스   [🔄 전체]│  ← 코스 타이틀 + 전체 다시 추천
│ ┌─ ① ☀️ 낮 ──────────┐ │
│ │ 스폿명        [🔄]     │ │
│ │ 📍위치 · ✓확인된 장소  │ │
│ │ "숲 산책이 좋아서" (이유) │ │
│ │ [지도 ↗]               │ │
│ └───────────────────┘ │
│  … 스텝 카드 반복 …         │
│ [📋 복사] [🔗 링크] [💾]   │  ← 액션 위계: 복사·링크 主, 저장 副
```
- **설계 포인트**: ① 생성 후 조건 영역 접기(요약 pill 한 줄로 축소) 여부 ② 액션 3개의 크기 위계 ③ 스텝 간 타임라인 연결선.

## S3. 스텝 카드 — 변형 4종 (컴포넌트 시트)

| 변형 | 구성 요소 |
|---|---|
| 기본형 | 슬롯 뱃지 · 스폿명 · 위치 · 추천 이유 1줄 · 가격 · 지도 링크 · 🔄 |
| verified형 | + "✓ 확인된 장소" 뱃지 (작게, 이유 줄 옆) |
| 가격 없음형 | 가격 줄 생략 시 레이아웃 |
| 후보 없음형 | 점선 빈 카드 + "이 조건에 맞는 장소를 찾지 못했어요" |

- **설계 포인트**: 요소가 7개라 카드가 무거워질 위험 — 이유·뱃지·가격은 보조 텍스트 크기로 눌러서 "이름·위치가 주인공" 유지.

## S4. 분위기 "⋯ 더보기"

- 기본 4종(로맨틱/힐링/미식/핫플) + `⋯` pill → 탭하면 **같은 줄에 인라인 펼침** (별도 시트 금지 — 화면 이동 없음 원칙).

## S5. 수신자 뷰 (링크로 열었을 때) ★신규 화면

```
│ ✨ 친구가 보낸 데이트 코스   │
│  스텝 카드들 (교체·저장 없음) │
│  [지도 ↗]만 유지            │
│ [ 나만의 코스 만들기 → ]    │  ← 유일한 CTA, 홈으로
```
- **설계 포인트**: 조건 영역·교체 버튼 없이 코스만. 받는 사람의 첫인상 = 제품의 얼굴이므로 S2보다 더 정돈된 레이아웃.

## S6. 저장한 코스 오버레이

- 기존 유지 + 상단에 안내 1줄: "카톡에 복사해두면 확실하게 보관돼요" (iOS 소실 대비).

## S7. 카톡 산출물 (화면 아님, 디자인 대상)

- **복사 텍스트 v2**: 헤더(✨ 지역·분위기) / 슬롯 이모지 + 스폿명 + (위치) / 지도 링크 / 이유 한 줄 — 카톡 말풍선에서 줄바꿈 미리보기 확인 필수.
- **OG 카드**: 정적 1종 (2:1, 로고+태그라인). 코스별 동적 OG는 서버 필요 → 안 함.

## S8. 상태·인터랙션

- 생성 시 스텝 카드 스태거 등장(50ms 간격) / 교체 시 해당 카드만 페이드 전환 / 토스트 1종 / `prefers-reduced-motion` 대응.
